# API معلومات الدولة من IP

## الملفات المطلوبة

ارفع مجلد `api` إلى `public_html/api/` بحيث يصبح العنوان `https://نطاقك/api/api.php`. داخل المجلد يجب وجود `api.php` وملف `GeoLite2-Country.mmdb` ومجلد `MaxMind/Db/Reader` بملفات المكتبة المبينة أدناه. هذا القاموس يغطي دول ISO 3166-1 التي لها رمز اتصال في مكتبة phonenumbers، وقد تشترك بعض الأقاليم في رمز دولة (مثل +1). لذلك رمز الاتصال ليس بالضرورة فريداً لكل بلد/إقليم.

## المكتبة

نزّل ZIP الرسمي: https://github.com/maxmind/MaxMind-DB-Reader-php/archive/refs/heads/main.zip . فك الضغط على جهازك، ثم انسخ محتويات `src/MaxMind/Db/` إلى `api/MaxMind/Db/`. لا تنسخ مجلد `src` كطبقة إضافية. الكود يستدعي ملفات PHP المطلوبة يدوياً دون Composer أو autoload.

الملفات المطلوبة: `Reader.php`، وداخل `Reader/`: `Decoder.php`, `InvalidDatabaseException.php`, `Metadata.php`, `UnsupportedPlatformException.php`, `Util.php`.

## قاعدة البيانات

أنشئ حساب GeoLite مجاني لدى MaxMind، وأنشئ License Key من لوحة الحساب، ثم نزّل GeoLite2 Country بصيغة MMDB من قسم التنزيلات وارفع الملف باسم `GeoLite2-Country.mmdb` داخل `public_html/api/`. MaxMind يشترط الحساب ومفتاح الترخيص للتنزيل، ويلزم إبقاء القاعدة محدثة وحذف الإصدار القديم عند صدور تحديث جديد وفق اتفاقية GeoLite. لا يوجد رابط تنزيل رسمي دائم/مفتوح دون مصادقة. لا تستخدم نسخ mirror غير رسمية للإنتاج؛ قد تكون قديمة أو لا تحقق شروط التوزيع.

## الرفع والاختبار

في cPanel افتح File Manager ثم `public_html` وأنشئ مجلد `api`. ارفع `api.php` وقاعدة MMDB، ثم ارفع شجرة `MaxMind/Db/` بالمحافظة على المسارات. ارفع `.htaccess` الموجود هنا لمنع الفهرسة والوصول المباشر إلى ملفات قاعدة البيانات. تأكد أن PHP 7.4 أو أحدث وأن امتدادات `mbstring` و`filter` فعالة. اجعل ملف MMDB قابلاً للقراءة من PHP، ولا تمنح صلاحيات كتابة عامة.

اختبر `https://mydomain.com/api/api.php?ip=8.8.8.8`. استخدم النطاق الحقيقي بدلاً من `mydomain.com`. ستتغير البيانات حسب إصدار GeoLite وموقع الإسناد؛ قاعدة البيانات تقريبية وليست إثباتاً للموقع الفعلي. إذا ظهر الرد الافتراضي فافحص مسارات المكتبة واسم ملف قاعدة البيانات وسجل أخطاء PHP.

## استخدامه من email.php

انسخ `getCountryInfo()` من `email-helper.php` إلى `email.php` أو استدعِ الملف بـ `require_once __DIR__ . '/email-helper.php';` ثم استخدم `$info = getCountryInfo($ip);`. الدالة تستخدم `file_get_contents` للاتصال بـ API الخاص بك فقط؛ أما `api.php` نفسه فلا يتصل بالإنترنت ويقرأ قاعدة MMDB محلياً. تأكد أن `allow_url_fopen` مفعّل على الاستضافة، أو استخدم cURL إن كان معطلاً.

## نقاط مهمة

القيم الافتراضية السعودية تُستخدم عند فشل القراءة أو IP غير صالح، كما طُلب. لا يُنصح بإرجاع بلد افتراضي عند فشل API في نظام أمني أو مالي لأنه قد يوهم بأن النتيجة مؤكدة. البيانات المستخدمة في القاموس مبنية وقت الإنشاء على أسماء عربية من CLDR ورموز اتصال من مكتبة phonenumbers؛ راجع الأقاليم ذات الرموز المشتركة إذا كان الاستخدام يتطلب تطابقاً رسمياً صارماً.
